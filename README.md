# AutoFix AI — Intelligent Code Analysis Platform

AutoFix AI is an AI-powered developer tool that detects bugs, suggests fixes, and evaluates code quality in real-time.

## Live Demo

https://your-vercel-link.vercel.app

## Problem

Developers spend a large portion of their time debugging and fixing code instead of building new features. Existing tools either detect only syntax errors or require manual effort to identify deeper issues.

## Solution

AutoFix AI analyzes code using AI and provides:

* Bug detection with severity levels
* Automatic code fixes
* Code quality scoring (performance, readability, security, maintainability)
* Refactoring suggestions
* Clear explanations for each issue

## Key Feature

The system not only detects bugs but also suggests improvements and best practices, acting like an intelligent code reviewer.

## Tech Stack

* Frontend: Next.js
* Backend: Node.js
* AI Integration: Generative AI models
* Deployment: Vercel

## How to Use

1. Paste your code
2. Select language
3. Click "Analyze with AI"
4. View results instantly

## IBM Technology Usage

IBM Bob was used as the development environment for building and testing the application. The AI-driven workflow aligns with the principles of IBM watsonx.ai by leveraging generative AI for code analysis and improvement.
